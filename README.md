Directorio curado de las mejores páginas y apps de inteligencia artificial: texto, imagen, vídeo, audio, código, productividad y más. Cada herramienta lleva una línea de qué hace, para elegir sin tener que abrir 20 pestañas.

Este repositorio es la selección. Si quieres el directorio entero, está en **[QueIA.es](https://queia.es)**: cientos de herramientas de IA indexadas una a una, en español, organizadas por categoría y actualizadas cada semana. Al final de cada categoría de aquí abajo tienes el enlace a la categoría equivalente del directorio.

Curado por [Jon Kraayenbrink](https://www.linkedin.com/in/jonathan-kraayenbrink/).
